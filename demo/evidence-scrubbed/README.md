# Scrubbed evidence

Copy of `demo\evidence\` produced by `python demo\scrub_evidence.py`. GUIDs are replaced by stable pseudonyms (the same id maps to the same pseudonym in every file), the tenant domain by `contoso-lab.onmicrosoft.com`, the resource-name suffix by `xxxx`, and public IPs by documentation addresses. Public Microsoft ids (first-party apps, built-in role and policy definitions) are kept. All data in the demo is synthetic.
